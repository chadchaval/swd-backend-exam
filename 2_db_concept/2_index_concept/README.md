## Response Section

Index (ดัชนี) ของฐานข้อมูล
คือโครงสร้างข้อมูลที่ช่วยให้ระบบค้นหาและดึงข้อมูลในตารางได้เร็วขึ้น โดยทำงานเหมือนกับหน้าสารบัญท้ายหนังสือ

ข้อดี
1.ค้นหาเร็วขึ้นมาก: จากต้องไล่ดูทุกแถว เหลือห้ามไปหาตามดัชนีเลย ยิ่งข้อมูลเยอะยิ่งเห็นผลชัด
2.ช่วย query: การ WHERE, JOIN, ORDER BY, GROUP BY ได้เขึ้น เพราะข้อมูลใน index เรียงไว้อยู่แล้ว ไม่ต้องมาเรียงใหม่ตอน query
3.ลดภาระรวมของระบบ: query จบเร็วก็จะรองรับ user พร้อมกันได้มากขึ้น

ข้อจำกัด
1.เขียน code ช้าลง: ทุก INSERT/UPDATE/DELETE ต้องไปอัปเดต index ทุกตัวที่เกี่ยวข้องด้วย ยิ่งมี index เยอะยิ่งช้า
2.พื้นที่: กินพื้นที่ disk เพิ่ม และแย่ง memory/cache กับข้อมูลจริง
3.ตารางเล็กมากไม่ต้องใช้: scan ทั้งตารางเร็วกว่าเปิด index อีก
4.ต้องดูแล: index บวม/กระจัดกระจายเมื่อใช้ไปนานๆ, index ที่ไม่มีใครใช้กลายเป็นพื้นที่เสียเปล่า
